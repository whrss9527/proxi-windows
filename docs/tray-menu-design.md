# 托盘菜单设计

本次优化按以下顺序完成与验证：

1. 顶部固定显示 Proxi 标识、彩色连接状态和当前配置，信息保持不可点击。
2. 配置集中在「代理配置」区，正在使用的配置有底色、彩色标记和勾选提示。
3. 测试、诊断和悬浮按钮作为常用快捷操作；网络接管与共享归在一个子菜单，低频偏好归入「更多」。
4. 菜单与子菜单统一使用原生字体、线条图标、间距和圆角悬停效果，快捷键与延迟独立对齐。
5. 保留系统菜单的方向键、Enter、Esc、子菜单、禁用和勾选状态；完整文字继续提供给辅助功能接口。
6. 检查深浅主题、高对比度、100% / 150% / 200% 缩放、长配置名和原生菜单资源清理。

菜单内容直接在原生菜单中绘制。窗口外框、阴影、子菜单箭头和菜单跟踪由 Windows 处理；不添加遮罩窗口或网页弹层。
