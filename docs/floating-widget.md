# 悬浮网速按钮

在「常规 → 悬浮网速按钮」或托盘右键菜单中开启。默认关闭，按需显示。

- 左侧是 Proxi 图形与连接角标，和托盘使用同样的状态规则。
- 右侧上行为下载、下行为上传，统计电脑的物理网络总流量，每两秒更新。
- 单击任意位置打开设置，代理开关仍在明确的菜单或设置项中。
- 按住拖动调整位置，松开后记住位置；拖动不会触发单击。
- 右键打开快捷菜单，可以切换配置、隐藏悬浮按钮或重置位置。
- 窗口置顶显示，不占任务栏，不抢走正在输入的焦点。显示器断开或分辨率改变时，位置会限制在可见工作区。

悬浮按钮独立显示电脑总网速；即使托盘网速选择「不显示」或「只算内置代理」，也保持同一统计口径。位置与是否显示只属于本机，不同步到其他电脑。

网速读取使用现有的网卡流量计数，不需要读取 Wi-Fi 名称或位置。命令行也可以用 `Proxi.exe float on` / `Proxi.exe float off` 控制。
