# Wi-Fi 名称与应用图标

## 什么时候读取 Wi-Fi 名称

读取名称是为了匹配自动切换规则。Windows 将这类 Wi-Fi 查询纳入位置权限，任务栏可能显示位置访问提示。

| 操作或配置 | Wi-Fi 名称查询 |
| --- | --- |
| 自动切换关闭 | 不查询 |
| 自动切换开启，但没有 Wi-Fi 名称条件 | 不查询 |
| 只按网关、DNS 后缀或网卡匹配 | 不查询 |
| 自动切换开启，且配置了非空的 Wi-Fi 名称条件 | 在网络检查中查询 |
| 手动立即应用包含 Wi-Fi 名称条件的规则 | 只为这次操作查询，不开启持续读取 |

关闭自动切换或删去最后一条名称条件后，页面立即清除旧名称，后续检查也不再调用 WLAN 查询。网卡、网关和按流量计费状态仍会更新，以便局域网共享和下载暂停正常工作。开发预览同样隐藏不需要读取的名称。

相关实现：`shouldReadWifiName`、`collectNetworkInfo`、`readNetworkInfo`、`App.watchNetwork`。`network_privacy_test.go` 验证不需要名称时查询次数为零，并验证手动应用不会开启自动切换。

## 图标的职责

- 应用图标是固定的 连接与分流图形，用在程序文件、安装包、菜单标题、侧栏和网页图标上。
- 托盘默认在应用图标上显示状态角标：配置颜色与勾号表示开启，灰色横线表示关闭，橙色表示警告或其他程序的代理，红色叉号表示配置错误。
- 「常规 → 外观」可切回开关样式：滑块位置表示开关，轨道使用配置颜色。两个预览分别展示开启与关闭。
- 菜单里的配置仍保留各自的颜色标记。应用身份、当前状态和配置选择各有明确的显示位置。

`tools/make_icons.py` 生成 ICO、文档图标和安装程序图片；`brand.go` 负责运行时托盘及菜单位图，`web/brand.svg` 负责设置页。

## 本地验证

Windows 上可以运行 `python tools/ui_test.py`；设置 `PROXI_BROWSER_CHANNEL=msedge` 可使用本机 Edge。`PROXI_GEO_DIR` 可指向已有的公开地理数据目录，减少测试对外网下载的依赖。按仓库约定，分别在未设置和设置 `PROXI_CORE` 时运行界面测试。

自动化测试使用隔离目录、模拟系统设置与测试代理，不向真实系统写代理设置。会修改真实 Windows 设置的 Go 测试仍须显式设置 `PROXI_TEST_REGISTRY=1`，应交由 CI 或测试虚拟机执行。
